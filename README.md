# 📅 College Timetable Website

A simple college timetable website created as a beginner web-development project. This project was developed in two versions to practice HTML first and then improve the design using CSS.

## 📌 Project Overview

The project displays a college timetable in a clear and organized webpage.

I developed it step by step:

* **Version 1:** Created the timetable using HTML.
* **Version 2:** Improved the appearance and layout using CSS.

## 🛠️ Technologies Used

### Version 1

* HTML5

### Version 2

* HTML5
* CSS3

## ✨ Features

* 📚 College class timetable
* 🕐 Class timings
* 📅 Days and subjects organized in a table
* 🎨 Styled timetable in Version 2
* 📱 Improved visual appearance using CSS
